# Retro Bowl fan-texture pack

This folder contains a set of retro-styled, 64x64 texture sheets inspired by the provided Retro Bowl PNGs. They are deliberately made to feel like a vintage sports-game art set while staying editable and easy to customize.

Files:
- `RetroBowl_texture_0.svg`
- `RetroBowl_texture_1.svg`
- `RetroBowl_texture_2.svg`
- `RetroBowl_texture_3.svg`

Design notes:
- 64x64 tile-friendly composition for sprite and UI use.
- Stadium/field palette with green, gold, and dark navy accents.
- Large shapes, high-contrast edges, and layered shading to mimic classic arcade sports styling.
- Fully editable SVG source for further refinement.

To export to PNG:
1. Open an SVG in a browser or vector editor.
2. Export at 2x, 3x, or 4x resolution for higher detail.
3. Use the resulting images as sprites, UI panels, or background tiles.

These are intended as a fanmade starting point for a Retro Bowl-inspired project and can be refined further to match a specific art direction.
